본인 권리 있는 트랙(본인 작곡·구매·교회 발행권)만 음악(②)에 사용하세요. 없으시면 아래 합법 무료 출처에서 직접 다운로드 후 음악 슬롯에 선택하세요:

  • YouTube Audio Library · youtube.com/audiolibrary — Google 운영. 장르 필터 "Christian"·"Cinematic"·"Inspirational" 등. YouTube 게시 시 Content ID 면제 보장(가장 안전).

  • Free Music Archive (FMA) · freemusicarchive.org — CC 라이선스. 트랙별 라이선스(CC0·CC-BY·CC-BY-SA 등) 명시 확인 필수. 검색: "christian"·"sacred"·"gospel".

  • Hymnary.org · hymnary.org — Public Domain 찬송가 데이터베이스(가사·악보·일부 녹음). PD 곡은 자유 사용·다만 *녹음 자체*의 권리는 녹음자에 따라 별도 확인.

💡 출처별 라이선스 조건(크레딧 표기·상업 사용 가부 등)이 다르니 다운로드 페이지의 라이선스 안내를 한 번 읽어 보세요. 영상 설명(③)에 크레딧 한 줄을 적어 두면 깔끔합니다.

왜 mp4 / webm 둘 다 나올 수 있나요?

브라우저 네이티브 인코더가 mp4(H.264+AAC)를 지원하면 mp4로, 아니면 webm(VP9/VP8)으로 저장합니다 — ffmpeg.wasm·외부 라이브러리 의존 0 원칙 때문입니다. 일반적으로 Safari·최신 Chrome은 mp4, Firefox·구버전 Chrome은 webm입니다. 둘 다 YouTube/대부분 SNS에 업로드 가능합니다.

🔒 브라우저 외 전송 0 · 서버 0 · 텔레메트리 0. 사진/음악/텍스트 바이트는 어디로도 나가지 않습니다. 트렌디 키워드는 본 브라우저의 LocalStorage에만 저장(다른 사용자/서버 미공유). 라이선스 책임은 사용자.

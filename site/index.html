사진 여러 장 + (옵션) 음악·메모·트렌디 키워드를 입력하면 9:16 세로 영상을 만든다. 모든 처리는 이 브라우저 안에서만 일어난다 — 사진· 음악·텍스트는 어떤 서버로도 업로드되지 않는다.

사진(EXIF 촬영 시각) + 동영상(파일 수정 시각)이 자동으로 옛것 → 최신 순서로 배치됩니다. 동영상의 원래 음향은 제거됩니다(음악·자동 BGM이 우선).
파일 선택 시: .mp3/.m4a/.wav/.ogg 등. 짧으면 무음 패딩, 길면 잘림. 라이선스 책임=사용자. 파일 없을 때 아래 자동 BGM이 켜져 있으면 자동 생성.
자동 BGM은 결정론 코드 진행(seed 기반)·CCM/예배에 어울리는 무드 옵션 포함. 본인 음악 파일이 있으면 그게 우선.
자동으로 메타데이터 해시태그(`#운동` 등)에 추가됨 · 기본 4태그 + 입력 키워드, 최대 15개. 이 입력은 이 브라우저 안에만 저장됨 (LocalStorage).
대기 중. 사진을 고르고 [영상 만들기]를 누르세요.

🖼🎬 사진 + 동영상 자동 배치 (v1.0)

①번 입력에 사진과 동영상을 함께 골라 둘 수 있습니다 (`.mp4`·`.mov`· `.webm` 등 브라우저가 디코드 가능한 모든 영상 포맷). 자동으로 EXIF 촬영 시각(사진) + 파일 수정 시각 (동영상)을 분석해 옛것 → 최신 순서로 배치됩니다 — 별도 정렬 조작 없이 입력 폴더만 던지면 됩니다.

동영상 음향 정책 (v1.0): 영상의 원래 소리는 *항상 제거*되며 음악(② 사용자 음악 파일 또는 🎶 자동 BGM)이 사운드트랙으로 사용됩니다. "음악이 있으면 동영상 음향 X" 정책이 명시 채택되었고, 모바일 안정성을 위해 *항상 mute*로 단순화되었습니다. 음악 없을 때 동영상 음향을 살리는 옵션은 별 turn 결정 잔존.

동영상 길이: 각 동영상은 컷당 초 (⑤번 입력) 만큼만 재생됩니다 — 동영상이 더 길면 그 시간에서 잘리고, 짧으면 마지막 프레임이 정지됩니다. 상태 줄에 🖼/🎬 아이콘으로 현재 컷이 사진인지 동영상인지 표시됩니다.

내용 기반 정렬(밝기·채도·색·얼굴 등 분석)은 별 turn 결정 잔존. 현재 v1.0은 *시간순*만 자동 적용.

🎵 8가지 BGM 무드 (v0.9 — 카테고리 확장)

v0.9에서 BGM 무드가 3개 → 8개로 늘었습니다. 각 무드는 독립적인 화성 진행·악기·드럼·이펙트·트랜지션 길이를 가집니다:

  • Ambient Pad — sine pad + AMSynth shimmer · 긴 reverb · 드럼 없음 · 1.0초 깊은 크로스페이드 (편안·예배)
  • Lo-Fi Piano — FM e-piano + 워킹 베이스 · kick+hat+rim · chorus+ping-pong delay · 3컷마다 페이드 블랙 (카페·재즈 화성)
  • Acoustic Arpeggio — FM bright arpeggio · sparse kick · 0.4초 빠른 크로스페이드 (밝은 일상 vlog)
  • Cinematic — C minor · AMSynth pad + 깊은 FM 베이스 · timpani 같은 kick · 깊은 reverb 7s · 4컷마다 페이드 블랙 · 1.2초 트랜지션 (영화 OST·웅장)
  • Hymn — I-IV-I-V 전통 진행 · 4성부 SATB voicing · church organ FM + choir pad · 드럼 없음 (고전 찬송가)
  • Jazz Café — ii-V-I 재즈 화성(Cmaj7-A7-Dm7-G7) · 2박/4박 comping · soft 1-3 kick + brush swing hat (스윙·브러시)
  • Upbeat Pop — I-V-vi-IV pop 진행 · pluck synth + 16분음 아르페지오 · 4-on-the-floor kick · 0.3초 빠른 트랜지션 (밝고 빠른 SNS)
  • Meditation — 단일 드론(C 5도 쌓기) · AMSynth drone + LFO shimmer · huge reverb 9s + long delay · 1.5초 매우 긴 트랜지션 (명상·요가)

모든 무드는 ImprovRNN chord-conditioned 멜로디 + Salamander 진짜 피아노 통합(v0.7) · 사용자 음악 파일이 있으면 그게 여전히 우선.

🎬 컷 사이 트랜지션 (v0.8 — 인트로/크로스페이드/페이드 블랙/아웃트로)

v0.8부터 컷이 단순 cut으로 붙지 않고 *부드러운 트랜지션*으로 연결됩니다. BGM 무드(켜져 있을 때)에 맞춰 자동 선택:

  • Ambient (예배·잔잔): 1.0초 크로스페이드 (느리고 깊은 호흡감) + 0.8초 인트로/아웃트로 페이드
  • Lo-Fi (재즈 BGM): 0.6초 크로스페이드 + 3컷마다 한 번씩 0.4초 "페이드 블랙" (시네마틱 호흡) + 0.6초 인트로/아웃트로
  • Acoustic (밝은 일상): 0.4초 빠른 크로스페이드 + 0.4초 짧은 인트로/아웃트로
  • BGM OFF (기본): 0.5초 인트로/아웃트로 + 0.6초 중간 크로스페이드

총 영상 길이가 트랜지션만큼 늘어납니다 — 인트로 + 모든 컷 + 컷 사이 트랜지션 + 아웃트로. 음악(자동 BGM·본인 파일 모두) 길이는 자동 조정. 메타 JSON `transitions` 필드에 사용된 프로파일과 페이드 블랙이 들어간 컷 번호가 기록됩니다.

🎶 자동 BGM이란 무엇인가요? (v0.7 — 4단계 품질 폴백)

BGM 토글을 켜고 [영상 만들기]를 첫 번째로 누르면 다음을 1회 다운로드 합니다(이후는 브라우저 캐시):

  • Salamander Grand Piano 샘플(~3-5MB·CC0 라이선스· Tone.js GitHub Pages 호스팅) — 진짜 피아노 음색
  • Magenta MusicVAE + ImprovRNN(~15-25MB·TensorFlow.js 포함· jsDelivr CDN + Google magentadata storage) — ML 멜로디 생성 (chord-conditioned)

품질 4단계 자동 선택:

  • T1+ (최고): ImprovRNN chord-conditioned 멜로디 + 진짜 피아노 + procedural 화성/베이스/드럼 — 멜로디가 *우리 화성에 정합*하게 생성됨 (v0.7 신규)
  • T1: MusicVAE 멜로디 + 진짜 피아노 (v0.6 동형)
  • T2: procedural 진행 + 진짜 피아노 (피아노만 로드 시)
  • T3: v0.5 FMSynth 폴백 (둘 다 실패 시)

어떤 경우에도 BGM은 *반드시* 나옵니다. 본인 권리 있는 음악 파일을 ②에 선택하면 그게 여전히 우선 사용됩니다.

한계: 가사·보컬·실 악기 앙상블은 여전히 없습니다. 브라우저 안 100% 로컬·합법 범위의 한계입니다.

모바일 첫 로드: ~40-90초 가능(v0.7 ImprovRNN 추가 분). 한 번 받으면 같은 브라우저에서 다음부터는 캐시. INVARIANT 'no upload' 보존: CDN은 정적 자원(코드·샘플·모델 가중치)만 전송하며 사용자 콘텐츠는 절대 송신하지 않습니다(자동 fetch 토큰 0건 자가검증).

왜 mp4 / webm 둘 다 나올 수 있나요?

브라우저 네이티브 인코더가 mp4(H.264+AAC)를 지원하면 mp4로, 아니면 webm(VP9/VP8)으로 저장합니다 — 외부 디코더 라이브러리 의존 없이 처리하기 위함입니다. 일반적으로 Safari·최신 Chrome은 mp4, Firefox·구버전 Chrome은 webm입니다. 둘 다 YouTube/대부분 SNS에 업로드 가능합니다.

🔒 사용자 콘텐츠(사진·음악·메모·키워드) 외부 전송 0. 자동 BGM은 브라우저 안에서 합성되어 영상에 결합 — 결과물 외부 전송 0. CDN은 *코드 라이브러리· 정적 오디오 샘플*만 받습니다(Tone.js·Salamander piano samples·@magenta/music· MusicVAE checkpoint — 모두 잘 알려진 공개 정적 자원). 사용자 콘텐츠는 어떤 CDN/서버에도 송신되지 않습니다. 트렌디 키워드는 LocalStorage에만 저장.

파일 선택 시: .mp3/.m4a/.wav/.ogg 등. 짧으면 무음 패딩, 길면 잘림. 라이선스 책임=사용자. 파일 없을 때 아래 자동 BGM이 켜져 있으면 자동 생성.
자동 BGM은 결정론 코드 진행(seed 기반)·CCM/예배에 어울리는 무드 옵션 포함. 본인 음악 파일이 있으면 그게 우선.
자동으로 메타데이터 해시태그(`#운동` 등)에 추가됨 · 기본 4태그 + 입력 키워드, 최대 15개. 이 입력은 이 브라우저 안에만 저장됨 (LocalStorage).

🎶 자동 BGM이란 무엇인가요? (v0.7 — 4단계 품질 폴백)

BGM 토글을 켜고 [영상 만들기]를 첫 번째로 누르면 다음을 1회 다운로드 합니다(이후는 브라우저 캐시):

  • Salamander Grand Piano 샘플(~3-5MB·CC0 라이선스· Tone.js GitHub Pages 호스팅) — 진짜 피아노 음색
  • Magenta MusicVAE + ImprovRNN(~15-25MB·TensorFlow.js 포함· jsDelivr CDN + Google magentadata storage) — ML 멜로디 생성 (chord-conditioned)

품질 4단계 자동 선택:

  • T1+ (최고): ImprovRNN chord-conditioned 멜로디 + 진짜 피아노 + procedural 화성/베이스/드럼 — 멜로디가 *우리 화성에 정합*하게 생성됨 (v0.7 신규)
  • T1: MusicVAE 멜로디 + 진짜 피아노 (v0.6 동형)
  • T2: procedural 진행 + 진짜 피아노 (피아노만 로드 시)
  • T3: v0.5 FMSynth 폴백 (둘 다 실패 시)

어떤 경우에도 BGM은 *반드시* 나옵니다. 본인 권리 있는 음악 파일을 ②에 선택하면 그게 여전히 우선 사용됩니다.

한계: 가사·보컬·실 악기 앙상블은 여전히 없습니다. 브라우저 안 100% 로컬·합법 범위의 한계입니다.

모바일 첫 로드: ~40-90초 가능(v0.7 ImprovRNN 추가 분). 한 번 받으면 같은 브라우저에서 다음부터는 캐시. INVARIANT 'no upload' 보존: CDN은 정적 자원(코드·샘플·모델 가중치)만 전송하며 사용자 콘텐츠는 절대 송신하지 않습니다(자동 fetch 토큰 0건 자가검증).

왜 mp4 / webm 둘 다 나올 수 있나요?

브라우저 네이티브 인코더가 mp4(H.264+AAC)를 지원하면 mp4로, 아니면 webm(VP9/VP8)으로 저장합니다 — 외부 디코더 라이브러리 의존 없이 처리하기 위함입니다. 일반적으로 Safari·최신 Chrome은 mp4, Firefox·구버전 Chrome은 webm입니다. 둘 다 YouTube/대부분 SNS에 업로드 가능합니다.

🔒 사용자 콘텐츠(사진·음악·메모·키워드) 외부 전송 0. 자동 BGM은 브라우저 안에서 합성되어 영상에 결합 — 결과물 외부 전송 0. CDN은 *코드 라이브러리· 정적 오디오 샘플*만 받습니다(Tone.js·Salamander piano samples·@magenta/music· MusicVAE checkpoint — 모두 잘 알려진 공개 정적 자원). 사용자 콘텐츠는 어떤 CDN/서버에도 송신되지 않습니다. 트렌디 키워드는 LocalStorage에만 저장.

사진 여러 장 + (옵션) 음악·메모·트렌디 키워드를 입력하면 9:16 세로 영상을 만든다. 모든 처리는 이 브라우저 안에서만 일어난다 — 사진· 음악·텍스트는 어떤 서버로도 업로드되지 않는다.

파일 선택 시: .mp3/.m4a/.wav/.ogg 등. 짧으면 무음 패딩, 길면 잘림. 라이선스 책임=사용자. 파일 없을 때 아래 자동 BGM이 켜져 있으면 자동 생성.
자동 BGM은 결정론 코드 진행(seed 기반)·CCM/예배에 어울리는 무드 옵션 포함. 본인 음악 파일이 있으면 그게 우선.
자동으로 메타데이터 해시태그(`#운동` 등)에 추가됨 · 기본 4태그 + 입력 키워드, 최대 15개. 이 입력은 이 브라우저 안에만 저장됨 (LocalStorage).

🎶 자동 BGM이란 무엇인가요? (한계·결정 배경)

Tone.js로 *브라우저 안에서* 코드 진행(chord progression)과 멜로디를 합성합니다. 외부 서버 0 호출·생성 결과 외부 전송 0 — INVARIANT 'no upload' 보존(Tone.js 라이브러리 자체만 페이지 로드 시 CDN 1회 다운로드).

한계: 진짜 *프로 음질*(Suno·Udio·CCM 메이저 곡 등)이 아닙니다 — "심플 신시사이저 배경 음악" 수준입니다. CCM 가사·보컬·실 악기는 없고, 화성 진행과 패드 사운드만 있습니다. 영상 분위기에 부족하면 본인 권리 있는 음악 파일을 ②에 선택하면 그게 우선 사용됩니다.

본격적인 ML 음악 생성 모델(Magenta MusicVAE 등)은 모바일 안정성과 모델 다운로드 비용(~수십 MB)을 이유로 v0.4에서는 도입하지 않았습니다. 향후 결정에 따라 별 turn에서 추가될 수 있습니다.

왜 mp4 / webm 둘 다 나올 수 있나요?

브라우저 네이티브 인코더가 mp4(H.264+AAC)를 지원하면 mp4로, 아니면 webm(VP9/VP8)으로 저장합니다 — 외부 디코더 라이브러리 의존 없이 처리하기 위함입니다. 일반적으로 Safari·최신 Chrome은 mp4, Firefox·구버전 Chrome은 webm입니다. 둘 다 YouTube/대부분 SNS에 업로드 가능합니다.

🔒 사용자 콘텐츠(사진·음악·메모·키워드) 외부 전송 0. 자동 BGM은 브라우저 안에서 합성되어 영상에 결합 — 결과물 외부 전송 0. Tone.js 라이브러리만 페이지 로드 시 CDN 1회 다운로드(코드 자체·사용자 콘텐츠 송신 0). 트렌디 키워드는 LocalStorage에만 저장.
